# 3&7 Training Platform - Technical Context

## Technology Stack
- **Frontend Framework**: React with Next.js
- **Styling**: TailwindCSS with custom theme configuration
- **Language**: TypeScript for type-safe development
- **Component Library**: Custom UI components with Shadcn/Radix inspiration
- **Version Control**: Git with GitHub

## Development Environment
- Modern JavaScript environment with TypeScript support
- Component-driven development approach
- Testing suite for UI components (to be implemented)

## Technical Constraints
- Must support a wide range of devices and browsers
- Accessibility compliance (WCAG AA standard target)
- Performance optimization for network-constrained environments

## Dependencies
- **UI Framework**: TailwindCSS with custom configuration
- **Component Primitives**: Custom implementation of form controls, toast notifications
- **Utility Libraries**: clsx, tailwind-merge for class composition
- **Animation**: CSS transitions with custom keyframes

## Infrastructure
- GitHub repository at `https://github.com/benedictnd/3n7testing`
- Branch strategy with feature branches merged to `indonesia-release`
